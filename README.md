Login\nPOST /api/auth/login\nBody: { email, password }\nReturns: { token, user }\n\n# Get current user\nGET /api/me\nHeaders: Authorization: Bearer <token>\nReturns: { id, email, displayName, roles }\n\n# Logout\nPOST /api/auth/logout\nHeaders: Authorization: Bearer <token>\n```\n\n### HSE Domain\n\n```bash\n# Inspections\nGET    /api/inspections              # List all\nPOST   /api/inspections              # Create new\nGET    /api/inspections/:id          # Get by ID\nPATCH  /api/inspections/:id          # Update\n\n# Hazards\nGET    /api/hazards                  # List all\nPOST   /api/hazards                  # Create new\nGET    /api/hazards/:id              # Get by ID\nPATCH  /api/hazards/:id              # Update\n\n# PICAs\nGET    /api/picas                    # List all\nGET    /api/picas/:id                # Get by ID\nPATCH  /api/picas/:id                # Update (approve)\n\n# Incidents\nGET    /api/incidents                # List all\nPOST   /api/incidents                # Create new\nGET    /api/incidents/:id            # Get by ID\nPATCH  /api/incidents/:id            # Update\n```\n\n**See:** [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md#api-contract) recreate\ndocker rm -f hdos-postgres\n# Run docker run command again from setup\n```\n\n### \"Address already in use\"\n```bash\n# macOS/Linux\nlsof -i :4000  # or :3000\nkill -9 <PID>\n\n# Windows PowerShell\nGet-Process -Id <PID> | Stop-Process -Force\n```\n\n### Login fails\n1. Check backend running: `curl http://localhost:4000/api/health/live`\n2. Reseed admin: `bun run db:seed`\n3. Check password in `.env`\n4. Review backend logs in Terminal 1\n\n**See:** [`docs/SETUP_PRODUCTION.md`](docs/SETUP_PRODUCTION.md#common-issues--troubleshooting) for full troubleshooting\n\n---\n\n## Contributing\n\n1.
